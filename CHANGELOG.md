# 1.0.0

-   Initial release: configurable initial width for journals and standalone pages, resizable down to a configurable minimum width, configurable sidebar width and an option to open journals with the sidebar collapsed.
-   The sidebar footer keeps the "Add Page" label on a single line with narrower sidebars.
-   Ownership Viewer compatibility: its markers are hidden when the sidebar is collapsed, so only the page number shows.
